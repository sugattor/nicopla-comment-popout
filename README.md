# NicoPla Comment Popout

ニコニコチャンネルプラスのコメント欄を別ウィンドウでポップアウト表示するブックマークレットです。

## 使い方

1. `bookmarklet-oneliner.js` の内容をコピー
2. ブラウザのブックマークに新規作成し、URLに貼り付け
3. 配信ページでブックマークレットを実行

コメント欄（入力・投稿・三点メニュー込み）がそのまま別ウィンドウにポップアウトし、元の画面ではコメント欄が隠れて動画が最大化されます。ポップアウトウィンドウを閉じると元に戻ります。

## 対応ページ

- 生配信ページ
- 動画ページ（アーカイブ含む）
