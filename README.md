# NicoPla Comment Popout

ニコニコチャンネルプラスのコメント欄を入力欄・投稿・NG登録込みでそのまま別ウィンドウにポップアウトし、元ページは動画列を全幅化して配信に集中できるブックマークレットです。

## 使い方

1. `bookmarklet-oneliner.js` の内容をコピー
2. ブラウザのブックマークに新規作成し、URLに貼り付け
3. 配信ページでブックマークレットを実行

ポップアウトウィンドウではコメントの閲覧・入力・投稿・三点メニュー（コメントコピー / NGユーザー登録）がそのまま使えます。元ページのコメント欄は非表示になり、動画が全幅に広がります。ポップアウトウィンドウを閉じると元ページに戻ります。

## 対応ページ

- 生配信ページ
- 動画ページ（アーカイブ含む）

## 実装メモ

- CSSは書き写さず、元ページの`cssRules`シリアライズ＋`link`コピーでポップアウトに注入する（MUI/emotion対応）
- コメント欄DOMはReact管理のため、入力送信と三点メニュー（NG）は元ページへ転写して動作させる
- 増分同期は`MutationObserver`＋`WeakMap`で追加・削除を反映
- 圧縮は terser（`node minify.js`で生成）
